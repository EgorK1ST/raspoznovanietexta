
# Scribble

Scribble — Telegram-бот для распознавания текста с фотографий и документов с помощью OCR.

## Возможности

- Распознавание текста с изображений.
- Предварительная обработка изображений с помощью OpenCV.
- Очистка распознанного текста.
- Сохранение результата в TXT-файл.

## Технологии

- Python
- aiogram 3
- PaddleOCR или EasyOCR
- OpenCV
- Pillow

## Установка

1. Клонируйте репозиторий:

```bash
git clone https://github.com/YOUR_USERNAME/scribble-bot.git
cd scribble-bot
```

2. Установите зависимости:

```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` и добавьте токен Telegram-бота:

```env
BOT_TOKEN=your_bot_token
```

4. Запустите бота:

```bash
python main.py
```

## Использование

Откройте бота в Telegram, отправьте `/start`, а затем фотографию с текстом. Бот распознает текст и отправит результат.
